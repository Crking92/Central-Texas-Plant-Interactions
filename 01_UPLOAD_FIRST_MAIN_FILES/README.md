# Central Texas Plant-to-Animal Ecosystem Dashboard

Public release prepared for Glass Root Garden®. © 2026 Glass Root Garden. All rights reserved.

## What changed in this release

- Removed staging workbooks, scripts, audits, duplicate exports, and download packages not used by the live page.
- Replaced the three bulk interaction CSV downloads with 256 smaller detail shards.
- Detailed interaction records now load only when a visitor opens a plant.
- Kept the full plant summary, visible scores, comparisons, caution flags, and source details.
- Added quick examples, a visible watermark, a short rights notice, and citation guidance.

## Important limitation

GitHub Pages is a public static website. These changes discourage easy bulk copying, but they cannot make browser-delivered data impossible to retrieve. Stronger access control would require moving plant details behind a server or API later.
